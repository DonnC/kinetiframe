# Reference sources

The Tavi model reference and empty studio plate were generated with OpenAI image generation
for this project. The plate was derived from the project's Loose Signal overview. These
bitmaps are visual references, not editable layered artwork or executable scene definitions.

Geometric stamp masters are authored in `tools/loose_signal/drawings.py`. Character kits also
use separately generated directional artwork; provenance is retained beside those sources.
The maintainer authorizes Apache-2.0 distribution of project-owned assets. See the
[asset guide](../../../assets.md) for contribution and attribution requirements.
